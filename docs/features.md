# Hostern 功能清单

## 终端

- 在同一窗口打开多个独立的本地或 SSH 终端页签，支持切换、重命名和关闭。
- 从用户主目录或指定工作目录启动本地终端。本地目录和 SSH 连接均可配置启动命令。
- SSH 支持主机地址和 SSH 配置别名，可选填用户名、端口和私钥路径，也可从自动识别的 `~/.ssh` 私钥列表中选择。认证和主机指纹确认在终端中完成。
- 远程主机支持双栏 SFTP 页签，左栏浏览本地目录，右栏浏览远程目录。支持上传、下载、创建文件夹、重命名、删除、复制路径和刷新。
- 会话结束后保留终端输出并显示退出码。
- 支持滚动回看、复制选区或终端输出、粘贴、全选、清屏、清除滚动历史，以及按住 ⌘ 点击打开链接。
- 可手动添加快捷命令，或将选中文本保存为快捷命令，再从右键菜单插入终端。

## 连接与项目

- 连接树支持创建、编辑和删除分组、SSH 主机和本地工作目录，支持拖放排序及移动分组。添加本地目录时可输入路径或使用系统目录选择器。
- 可显示或隐藏连接树，也可切换到项目视图，让已保存的本地工作目录在左侧窄栏中各占一个页签。
- 项目视图底部的「＋」支持添加本地目录、新建 SSH 配置、加入已有 SSH 配置和恢复已关闭的本地目录页签。可编辑项目配置、自定义页签文字，使用 Emoji 或选择本地 PNG、JPEG 作为图标。右键选择「关闭项目页签」可隐藏本地目录或 SSH 页签，保留原有配置和终端会话。
- 项目间切换时会保留各自的终端会话，可在当前项目中打开多个终端页签。
- 连接配置、项目中的 SSH 配置与设置保存在本地。

## 设置

- 界面语言支持简体中文和英文，主题支持跟随系统、浅色和深色。
- 界面和终端可分别设置字体、字号与加粗，设置页提供终端字体预览。
- 可选择启动时打开本地终端，或仅打开主窗口。
- 可搜索设置，自定义、停用或恢复新建本地终端、关闭页签、切换侧栏和打开设置的快捷键。
